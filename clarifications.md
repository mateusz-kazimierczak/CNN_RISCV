From the project md file: "You may download models from https://huggingface.co/litert-community. Or you may convert other downloaded models from Pytorch to LiteRT. It's recommended to quantize and port baremetal LiteRT models."
The emphasis in on the LiteRT framework. You cannot run direct Python codes on RV64IMC without converting to a C/C++-based runtime, e.g., LiteRT Micro. Given a LiteRT C/C++ model (B0 version), it is still possible to configure and streamline the LiteRT frameworks to improve the performance, e.g., static memory layout for better caching and add only used operators (B1 version).
Of course, this is just one option. You can also use ExecuteTorch C++ runtime to process converted .pte file from Pytorch. Please investigate and choose your implementation strategies. They are similar but involve different toolsets and libraries. Basically LiteRT is easier to port new ISA but it probably lacks support for some Transformer operators. ExecuteTorch requires more efforts at porting operators to new ISA. Use AI prompts to check the exact work flow of both runtimes and perhaps try  to use your target model on both runtimes to check which actually works  (without any performance evaluation or optimization). Note that Transformer-based models are only optional in the project. There are other DNN-based choices.
